# Yo Bowl Carrollton — reference assets

This directory preserves the real photography from the original Yo Bowl
Carrollton site that this template was generalized from. The repo's working
asset directories (`gallery-photo/`, `menu-photo/`, `location-photo/`,
`uploads/`) now hold generic placeholders so a fresh clone builds and runs
without depending on — or hotlinking — any specific restaurant's photos.

These files aren't referenced by `config.json` or copied into `dist/`. They're
here purely as a real-world reference for size, aspect ratio, and format when
you're sourcing replacement photography for your own restaurant:

| Directory | What it shows |
|---|---|
| `gallery-photo/` | Public gallery photos + the `photos.json` that listed them |
| `menu-photo/` | Featured menu images |
| `location-photo/` | Storefront and parking-guide photos |
| `uploads/` | Owner-uploaded scratch space (misc photos, in-progress edits) |
